# 🤝 java-shareit

Платформа для аренды вещей. Пользователи могут добавлять вещи, которые готовы дать на время, бронировать их на определённые даты и оставлять отзывы после использования. Если нужной вещи нет, можно создать запрос — другие пользователи смогут на него откликнуться. Проект построен на микросервисной архитектуре: отдельный сервис-шлюз обрабатывает запросы и проверяет данные, а основной сервис занимается бизнес-логикой и работой с базой PostgreSQL. Все компоненты упакованы в Docker-контейнеры.

---

## ✨ Функциональность

- Добавление, обновление и поиск вещей для аренды
- Создание запросов на вещи, которых нет в наличии
- Бронирование вещей на определённые даты
- Подтверждение или отклонение бронирования владельцем
- Добавление отзывов после завершения аренды
- Пагинация для всех методов, возвращающих списки
